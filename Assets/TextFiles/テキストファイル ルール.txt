テキストファイル ルール

・コメントアウト
　　　#…

・キャラに話させたいとき Nはナレーション
　　　name「…」
　　　N:…

・選択肢 /で区切る 選択肢どれか終わったらendに飛ぶ
　　　<選択肢:…/…>
　　　
　　　<選択肢:1>{
	…
　　　}
　　　<選択肢:2>{
　　　}
	…
　　　<選択肢:n>{
	…
　　　}
　　　<選択肢:end>


・数値変化 数の例(3,-2)
　　　<値変化:変数名/数>

・フェードイン、フェードアウト
　　　<フェードイン:秒数>
　　　<フェードアウト:秒数>

・立ち絵 操作名:出場,移動(サイズ変更),退場,立ち絵変更
　　　<立ち絵:出場/キャラ名/立ち絵番号/初期位置/初期サイズ>
　　　<立ち絵:移動/キャラ名/移動先位置/サイズ/秒数>
　　　<立ち絵:退場/キャラ名>
　　　<立ち絵:立ち絵変更/キャラ名/立ち絵番号>

・背景を変える
　　　<背景:背景番号or背景名>

・文中に変数を入れる場合
　　　…{$変数名}…
